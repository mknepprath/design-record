# mknepprath.com

Personal site at [mknepprath.com](https://mknepprath.com): writing, an activity feed, and small projects such as [lilt](lilt.md). Next.js on Vercel, pages router.

## Design direction

A handmade look of physical objects on a surface. Each kind of content is its own object, not a recolored card. From Claude Code's memory notes:

| Content | Object |
| --- | --- |
| Run, walk, hike | Luggage sticker with route map |
| Film | Movie ticket |
| Repo or commit | Terminal window |
| Music | Player card |
| Toot | Sticky note |
| Blog post | Newspaper clipping |
| Book | Library catalog card |
| Photo | Polaroid |

Rules: consistent 3px stroke weight, slight random rotation, slide-in on scroll, and restraint over decoration ("if a detail needs explaining, cut it").
